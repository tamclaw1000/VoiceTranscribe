- [ ] NF0014: Read audio directly from AVI files, without an ffmpeg step in front. Measured while scoping it, so none of this needs re-deriving: AVFoundation cannot open the AVI at all (`isReadable: false`, zero tracks, duration 0), so the existing `AVAssetReader` fallback throws and the app reports "Could not read …"; CoreAudio cannot open the extracted raw `.ac3` either (`afinfo` fails, `AVURLAsset` reports a track with no codecs and `startReading` fails with -12138). But the same AC-3 bitstream decodes fine inside `.mov`/`.mp4` (307,098 frames), and `AVAssetWriter` accepts an AC-3 format description (`canAdd: true`, 600 frames muxed and re-read). Plan: an in-app RIFF/AVI demux — the container's own codec tag is zeros, so the codec must be sniffed from the bytes — plus a remux to a temp file, then the existing decode path. `scripts/extract-audio` is the workaround until then.
